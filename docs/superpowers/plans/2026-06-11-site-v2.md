**Tech Stack:** Astro 6, vanilla TS, CSS. No new runtime deps.

**Spec:** `docs/superpowers/specs/2026-06-10-site-v2-design.md` · Brand: `docs/brand.md`

**Branch:** `feat/site-v2` (already created; spec+mockups committed).

### Task S2: cable hero + real typewriter

**Files:** Create `site/src/scripts/cable.ts`, `site/src/scripts/typewriter.ts`; modify `site/src/components/Hero.astro`.

- [ ] `cable.ts`: port the IIFE from `docs/superpowers/mockups/site-v2-hero-cable.html` `<script>` (left smoothstep converge ×3 with draw-in then dash-flow; right tight braid amp 9px/wavelength≈78px/phases 120° with over/under dash rhythm) into an exported `initCable(svg: SVGSVGElement)`; guard at top: `if (matchMedia('(prefers-reduced-motion: reduce)').matches)` → render all paths fully drawn, static, and return.
- [ ] `typewriter.ts`: REAL per-character typing (spec acceptance criterion). Implementation: each line's text pre-rendered in the DOM (a11y/no-JS) inside `<span class="tw-line">`; the script measures `textContent`, empties visible text via `visibility` trick — concretely: wrap chars are NOT individually spanned; instead use a JS interval appending one char at a time from the stored string into the line, with a single caret element moved to the end of the currently-typing line; on completion of all lines the caret stays blinking on the last. No-JS/reduced-motion: full text already visible (script removes nothing before checking the media query). Export `initTypewriter(container, {cps: 28})`.
- [ ] Hero.astro: markup per mockup §2 (h1/subline/terminal 4 persona lines/install tabs/stats strip); `<script>` block imports and runs both modules; install tabs switch via a 6-line inline script (buttons toggle `data-cmd` text + copy button reuses the v1 clipboard pattern with double-click-safe restore).

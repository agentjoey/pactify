# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub:
[open a security advisory](https://github.com/agentjoey/pactify/security/advisories/new).
Please do not open a public issue or post exploit details publicly.

Include the affected command or component, the pactify version (`pactify version`), the
harness and its CLI version if one is involved, and steps to reproduce. You will get an
answer in the advisory thread.

## Supported versions

Fixes go into the latest release. See the
[releases](https://github.com/agentjoey/pactify/releases) and the
[security notes](https://pactify.dev/security) for what each access mode enforces.

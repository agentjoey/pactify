# Squad M3.1+M3.2 Implementation Plan (canvas + dispatch)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The serve dashboard grows author powers: a React Flow orchestration canvas (M3.1) and drag-to-dispatch + review flow (M3.2), backed by a dir-aware engine, an additive `deps` protocol extension, and a serve author API acting as a configured seat.

**Architecture:** Four layers, built bottom-up: (Q1) `pact.At(dir)` makes every verb dir-aware (CLI/MCP keep cwd behavior via wrappers); (Q2) optional `deps` on assign + join gate, additive to protocol v1; (Q3-Q4) serve gains POST verb endpoints executing as `--seat` with per-project mutex; (Q5-Q8) web/ gains a Canvas view (@xyflow/react), draft-task build mode, drag dispatch, review buttons, SSE-live updates. Embedded dist rebuilt at the end (repo convention: `internal/serve/dist` is committed for go:embed).

**Key existing facts:** engine funcs in `internal/pact/engine.go` (Assign/Accept/Changes/Merge/Checkpoint/Join/Status/Validate, all cwd-bound via `paths.Dir()` + `gitx` with `"."`); serve routes in `internal/serve/api.go` (`GET /api/projects`, `/api/projects/{id}/state`, `/api/projects/{id}/events` SSE); registry maps name→path; web/ is React19+Vite+TS (`src/lib/{api,types,derive}.ts`, `src/components/{TopBar,Agents,Board,RightRail}.tsx`), tests vitest; STATE DTO in `internal/serve/dto.go`.

**Spec:** `docs/superpowers/specs/2026-06-10-phase3-squad-design.md` · Brand: `docs/brand.md`

**Branch:** `feat/squad-canvas`.
